What this page does

  • It asks Arc's public RPC for the events that name the address, the receipt of each transaction they belong to, and the address's balance at the start and the end of the period (plus its transaction count when the sums leave a remainder). That is all it reads.
  • It sends the address only to the RPC endpoint (rpc.mainnet.arc.io, or rpc.testnet.arc.io when you choose Testnet). No cookie, no storage, no analytics, no outside script, font or image.
  • It deploys no contract and sends no transaction. It cannot move money.
  • There is no indexer behind it: long periods take minutes because the public RPC allows about two requests a second.
  • A tick on the balance check appears only when the sums were computed and match the chain to the last unit.
